# ⏰ Python Digital Clock

A simple Digital Clock application built using Python and Tkinter.

## Features
- Displays the current time
- Updates every second
- Shows the current date
- Simple GUI using Tkinter

## Technologies Used
- Python
- Tkinter
- time module
